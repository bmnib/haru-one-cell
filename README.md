# 하루 한 칸

오전·오후·밤 루틴과 오늘 목표를 가볍게 체크하고
하루의 흐름을 기록하는 Notion 위젯

## 하루 한 칸은

한 번 루틴이 무너지면 하루 전체를 놓치기 쉬운 문제를 줄이고,
하루를 오전·오후·밤의 작은 단위로 나눠
부담 없이 다시 시작할 수 있도록 만든 위젯입니다.

## 주요 기능

- 오전·오후·밤 루틴 체크 및 편집
- 오늘 목표 입력 및 완료 체크
- 완료 항목을 기준으로 오늘의 흐름 자동 계산
- 5단계 오늘의 기분 기록 및 선택 해제
- 한 줄 회고 기록
- 같은 기기·브라우저 환경에서 기록 유지

## 사용 방법

1. 아래 배포 링크에서 바로 사용할 수 있습니다.
2. Notion에서 `/embed` 블록을 추가합니다.
3. 하루 한 칸 링크를 붙여 넣고 폭과 높이를 조절합니다.
4. 기본 루틴은 연필 버튼을 눌러 원하는 내용으로 수정할 수 있습니다.

## 저장 방식

기록은 현재 사용하는 기기·브라우저 환경에 저장됩니다.

같은 환경에서는 새로고침 후에도 기록이 유지되지만,
현재 버전에서는 다른 기기나 브라우저와 자동으로 동기화되지 않습니다.
